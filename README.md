# VEIL — установщики

VEIL — простой VPN-клиент для Windows 10 и 11 (64 бит). Он подключается к серверам по подписке, которую вам дал владелец сервера, и умеет пускать российские сайты напрямую, а всё остальное — через VPN. Серверов в самой программе нет: без ссылки на подписку VEIL ни к чему не подключается.

Здесь лежат только готовые установщики и файлы для автообновления. Исходный код VEIL закрыт.

## Как установить

1. Откройте раздел [Releases](https://github.com/nt90380-design/veil-releases/releases/latest) и скачайте `VEIL-Setup-X.Y.Z.exe` (самую новую версию).
2. Запустите скачанный файл. Windows спросит разрешение на изменения — нажмите «Да»: VEIL ставится в `C:\Program Files\VEIL`.
3. Установщик предложит ярлык на рабочем столе и запуск вместе с Windows; обе галочки можно оставить.
4. В VEIL откройте «Серверы», добавьте ссылку на подписку и нажмите на переключатель на главной.

Ставьте VEIL из своей учётной записи Windows (не из чужой учётной записи администратора).

Если браузер пишет, что файл «обычно не скачивается», сохраните его: в Edge — «…» → «Сохранить» → «Показать больше» → «Всё равно сохранить», в Chrome — «Сохранить» (или «Всё равно сохранить»).

### Если Windows пишет «Windows защитил ваш компьютер»

У установщика нет платной цифровой подписи, поэтому фильтр SmartScreen может его остановить. Это ожидаемо:

1. В окне «Windows защитил ваш компьютер» нажмите **Подробнее**.
2. Появится кнопка **Выполнить в любом случае** — нажмите её.

Так нужно делать только при первой установке: дальше VEIL обновляется сам.

## Обновления и их подпись

VEIL раз в день (и по кнопке «Проверить обновления» в настройках) читает файл `latest.json` из последнего релиза этого репозитория. В нём номер версии, ссылка на установщик, его размер и контрольная сумма SHA-256.

- Рядом лежит `latest.json.sig` — цифровая подпись Ed25519 над точным содержимым `latest.json`. Открытый ключ проверки встроен в VEIL, а закрытый есть только у автора и никогда не попадает в репозиторий или релиз.
- VEIL отвергает обновление без подписи или с неверной подписью, с другим адресом скачивания, с несовпадающими размером или SHA-256, а также версию, которая не новее установленной.
- Скачивается установщик только с GitHub по HTTPS. Перед запуском VEIL ещё раз сверяет его SHA-256, затем тихо ставит новую версию и сам подключается снова.

Проверить скачанный вручную установщик можно в PowerShell: `Get-FileHash .\VEIL-Setup-X.Y.Z.exe -Algorithm SHA256` — результат должен совпасть с полем `sha256` в `latest.json` того же релиза.

## Удаление

«Параметры → Приложения → Установленные приложения → VEIL → Удалить». Удаление закрывает VEIL, возвращает настройки сети и спрашивает, удалить ли ваши серверы и настройки.

- VEIL использует сетевое ядро [sing-box](https://github.com/SagerNet/sing-box) 1.14.4 без изменений. sing-box распространяется по лицензии GNU GPL-3.0-or-later. В установленной программе лежат уведомление об авторских правах sing-box (`C:\Program Files\VEIL\resources\core\LICENSE`) и полный текст лицензии GPL-3.0 (`C:\Program Files\VEIL\resources\core\COPYING`). Исходный код именно этой версии: https://github.com/SagerNet/sing-box/tree/v1.14.4
- Базы российских сайтов — официальные rule-set от SagerNet: https://github.com/SagerNet/sing-geosite и https://github.com/SagerNet/sing-geoip
- Интерфейс работает на Electron (лицензия MIT) и Chromium; их лицензии лежат рядом с программой (`LICENSE`, `LICENSES.chromium.html`).
